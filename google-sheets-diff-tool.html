Spreadsheet diff

Google Sheets diff tool

SheetDiff gives Google Sheets users a repeatable way to diff two tabs, review changed cells, and export or highlight results without leaving the spreadsheet.

Diff rows by key

Instead of comparing row 10 to row 10, SheetDiff matches records by the key you choose. That makes it useful for order exports, finance reports, inventory lists, CRM data, vendor files, and other sheets where row order can change.

See every changed value

The report shows the key, changed column, value in Sheet A, value in Sheet B, and row numbers on both sides. Pro users can also create side-by-side views and highlight source rows.

Handle real spreadsheet mess

SheetDiff detects duplicate keys, supports ignored columns, column mapping, custom ranges, case-sensitive comparison, fuzzy key matching, and numeric tolerances for practical spreadsheet comparison workflows.
