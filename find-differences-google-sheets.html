Find differences

Find differences between Google Sheets tabs

SheetDiff helps you quickly spot records that were added, removed, changed, or left matching between two tabs in the same Google Sheets spreadsheet.

Added and missing rows

See rows that exist only in Sheet A or only in Sheet B. This is useful for imported files, customer lists, payroll exports, transaction reports, and operations data that should stay in sync.

Changed cells

For matched records, SheetDiff lists each changed column with the value from both sheets and the row numbers on both sides, making review faster than scanning manually.

No upload workflow

SheetDiff runs as a Google Sheets add-on. Comparison data stays in your spreadsheet and Apps Script runtime; the only external request is license verification if you activate Pro.
