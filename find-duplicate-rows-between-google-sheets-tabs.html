Duplicate keys

Find duplicate rows between Google Sheets tabs

Real spreadsheets often contain duplicate invoice numbers, SKUs, emails, names, or IDs. SheetDiff flags duplicate keys during comparison so they are not silently merged.

Detect duplicate keys

When the selected key appears more than once, SheetDiff adds duplicate warnings to the comparison report instead of guessing which rows should match.

Review candidates

Pro users can generate a duplicate review sheet that lists candidate rows and lets the user choose which records should be paired.

Finish the comparison

After duplicate choices are applied, SheetDiff regenerates the report with updated missing rows, changed rows, and matching rows.
